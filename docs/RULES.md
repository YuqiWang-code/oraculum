# 规则与版本

## 版本

- `RULESET_VERSION = 1.0.0`
- `DATASET_VERSION = 1.0.0`

历史记录同时保存两个版本号；未来改算法会升版本，旧记录按旧版重放，不静默覆盖。

## 梅花时间起卦 meihua_time_v1（资料 5.2）

1. 年支数：子1…亥12。
2. A = 年支数 + 农历月 M + 农历日 D。
3. B = A + 时支数 H。
4. 上卦 = A mod 8（0→8），下卦 = B mod 8（0→8）。
5. 动爻 = B mod 6（0→6）。
6. 先天数：1乾 2兑 3离 4震 5巽 6坎 7艮 8坤。
7. 动爻所在经卦为"用"，另一为"体"。
8. 互卦：本卦二三四爻下互、三四五爻上互。

## 六爻排盘 v1（资料第6节）

- 八宫表、世应表、纳甲表直接表驱动（`src/data/`）。
- 六亲以宫五行为"我"：生我父母、同我兄弟、我生子孙、我克妻财、克我官鬼。
- 六神按日天干起初爻，固定循环 青龙→朱雀→勾陈→螣蛇→白虎→玄武。
- 旬空由日柱干支查六旬。
- 伏神：本卦六亲缺失时从本宫纯卦同爻位查找（v1 只定位）。
- 神煞：驿马、桃花、华盖、天乙贵人，低权重（六神+神煞合计 ≤ ±4）。

## 六爻评分 v1（资料 11.2，基准 50，v1 简化可解释版）

- 世爻得月建/日辰生扶加分，受克扣分。
- 动爻数影响变化趋势分。
- 卦象主题 ±6。
- 神煞 ≤ ±4，可在设置关闭。

## 流派差异说明

- 体用划分、卦辞用字、神煞起法在不同古籍/流派间存在差异。v1 一律采用资料库 `资料/传统术数资料库_智能推理与预测_v1.md` 所列默认规则并标注版本。未来可在设置中切换流派。
