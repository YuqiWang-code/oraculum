# 更新日志

## v1.0.0（2026-09-17）

首个可运行版本。

### 新增
- Vue 3 + TypeScript + Vite + Pinia + Vue Router + Vitest + PWA(Dexie) 工程骨架。
- 梅花易数时间起卦（meihua_time_v1）：本卦、互卦、变卦、动爻、体用五行。
- 历法引擎封装 lunar-javascript：公历/农历/年月日时干支、节气、月建、旬空。
- 六爻排盘：八宫、世应、纳甲、六亲、六神、伏神定位、神煞（驿马/桃花/华盖/天乙贵人）。
- 0–100 传统规则评分 + 五档（大凶/凶/平/吉/大吉）+ 评分证据链。
- 本地模板化现代解读（不调云端 AI）。
- IndexedDB 历史记录、搜索、导出/导入 JSON。
- 知识库页、设置页、关于页、免责声明。
- PWA manifest + service worker，可离线、可添加到主屏幕。
